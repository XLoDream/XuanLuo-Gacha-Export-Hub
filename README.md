# XuanLuo Gacha Export Hub

璇洛抽卡祈愿工具 —— 原神祈愿 · 崩铁跃迁 · 绝区零调频 · 鸣潮唤取的抽卡记录管理与导出工具。

一款基于 Electron 的 Windows 桌面应用，支持从游戏本地缓存自动读取抽卡链接、在线增量拉取记录、多账号管理，并导出为标准 UIGF v4.1 JSON 或 Excel 表格。

## 功能特性

- **四游戏支持**：原神（祈愿）、崩坏：星穹铁道（跃迁）、绝区零（调频）、鸣潮（唤取）
- **自动读取链接**：从游戏日志 / 本地缓存中自动定位抽卡记录链接，无需手动复制
- **增量更新**：命中本地最新记录即停止翻页，只拉取新增部分
- **多账号管理**：自动按 UID 分账号存储，下拉切换
- **导出格式**：
  - UIGF v4.1 JSON（自动补全 item_id）
  - Excel 表格（按卡池分工作表，含保底计数、星级配色）
  - 鸣潮支持 Excel 导入
- **统计视图**：卡池统计、保底进度、记录筛选（星级 / 类型 / 搜索）
- **五星总览**：按卡池横向切换展示所有 5★ 物品，含图标与分页
- **崩铁配队**：根据已抽到的角色/光锥生成已有角色面板，支持命途/属性/星级筛选与命座显示；点击角色查看推荐配队，已有角色高亮、未拥有置灰
- **深浅色主题**：一键切换，各游戏独立主题色

## 下载安装

从 [Releases](https://github.com/XLoDream/XuanLuo-Gacha-Export-Hub/releases) 下载最新的 `XuanLuo-Gacha-Export-Hub-Setup-<版本号>.exe`，运行安装程序即可（可选安装目录，自动创建桌面与开始菜单快捷方式）。

> 未做代码签名，Windows SmartScreen 可能提示"未知发布者"，选择"仍要运行"即可。

## 使用说明

1. **原神 / 崩铁 / 绝区零**：先在游戏内打开一次抽卡「历史记录」页面，然后在本工具对应页面点击「更新数据」
2. **鸣潮**：在游戏内打开一次「唤取记录」页面后点击「更新数据」（链接约 24 小时有效，过期需重新打开记录页）
3. **导入**：支持 UIGF v4.1 JSON 文件导入（鸣潮支持 Excel 导入）
4. **导出**：记录页可导出 UIGF JSON 或 Excel；总览页支持批量导出全部游戏

## 数据存储

所有数据仅保存在本地，不会上传：

```
%APPDATA%\gacha-export-hub\userdata\
├── app.config.json      # 应用配置与当前选中账号
├── genshin\ <uid>.json  # 原神账号记录
├── hsr\     <uid>.json  # 崩铁账号记录
├── zzz\     <uid>.json  # 绝区零账号记录
└── wuwa\    <uid>.json  # 鸣潮账号记录
```

数据目录可在「设置 → 数据与存储」中更改。

## 从源码构建

环境要求：Node.js 18+

```bash
# 安装依赖
npm install

# 开发模式运行
npm start

# 打包绿色版（免安装文件夹）
npm run pack

# 打包 NSIS 安装包（输出到 dist\）
npm run dist
```
